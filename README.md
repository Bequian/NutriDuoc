# Aplicacion NutriDuoc
### Se creo aplicacion en base a los requerimientos de la primera semana de la asisgnatura.

#### Pantalla Principal LoginScreen

Emula un login que verifica valores almacenados en un array.

usuarios de prueba incluidos en array: 

* usuario: user@user.cl | password: 123 
* usaurio: user1@user.cl | password: 123

#### RegistroUsuarioScreen

Emula el registro de un usuario, no se almacena información es solo simulación, al llenar los campos y aceptar los TYC muestra una alerta que indica que el registro fue exitoso y vuelve al Login.

#### PasswordRecoveryScreen

Emula la recuperacion dela contraseña, al ingresar un valor muestra una alerta indicando que las indicaciones fueron enviadas al correo y redirige al login.

### MinutasRecetasScreen

Es un array con 5 recetas, se muestra 1 para cada día, se agrego un Select para filtrar por día.
